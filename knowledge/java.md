# Java 与 JVM

## JVM 内存区域

线程私有区域包括程序计数器、Java 虚拟机栈和本地方法栈；线程共享区域主要包括堆和方法区。HotSpot 使用元空间实现方法区，元空间主要使用本地内存。

## 垃圾回收

垃圾回收首先通过可达性分析判断对象是否存活。常见收集器包括适合低延迟场景的 G1、ZGC。选型要结合堆大小、吞吐目标、暂停时间目标和应用分配速率，不能脱离业务只比较算法。

## 并发

`volatile` 保证可见性与一定的有序性，但不保证复合操作的原子性。`synchronized` 同时提供互斥和 happens-before 语义。并发问题分析应从原子性、可见性、有序性三个维度展开。

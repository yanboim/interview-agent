# 页面清单

| 页面/界面 | 路由 | 主要内容 | 关键状态 |
|---|---|---|---|
| 身份覆盖层 | 产品工作区内 | 登录、注册、找回密码 | 初始、提交、错误、成功 |
| 今日训练 | `/today` | 目标、建议、提醒、快速入口 | 首次、空、加载、已配置 |
| AI问答 | `/chat/{sessionId?}` | 消息、输入、流式回答、声明证据、来源、点赞/点踩 | 空、生成、无证据、证据冲突、取消、错误 |
| 会话历史 | `/history` | 搜索、日期分组、重命名、归档 | 空、筛选、批量操作 |
| 模拟面试 | `/interviews/{interviewId?}` | 配置、问题、回答、评分、进度 | 创建、答题、评分、完成、恢复 |
| 简历中心 | `/resumes/{resumeId?}` | 上传、历史、评估、证据、优化稿、DOCX导出 | 校验、解析、分析、失败、事实待确认、编辑冲突、可导出 |
| 面试复盘 | `/reviews/{reviewId?}` | 音频/文本、逐字稿、说话人、逐题与整体报告 | 外发确认、转写、待确认、编辑冲突、分析、失败、完成 |
| 能力画像 | `/profile` | 综合分、维度、趋势、主题、薄弱点 | 空数据、筛选、正常 |
| 学习计划 | `/learning` | 任务、结果感知复习、训练计划预览和Agent运行 | 空、待确认、运行、失败、取消、恢复、完成 |
| 设置 | 工作区弹窗 | 主题、头像、账号、提醒偏好和训练记忆 | 查看、待确认、确认、拒绝、纠正、删除、错误 |
| 管理后台 | `/admin` | 概览、资源、用户、分析、审计、交互、发布、知识 | 未登录、加载、错误、危险操作 |

简历定向配置复用模拟面试页面，在创建状态提供通用/简历来源选择、版本摘要和来源
标识；未完成、已删除或不属于当前用户的分析不可选择。

## 共用覆盖层

- 确认对话框：删除、归档或高风险操作；
- Toast：短时成功、失败和提醒；
- 恢复码对话框：只在生成时完整展示；
- 目标设置对话框：首次使用和主动修改；
- 全局错误边界：避免空白页并提供恢复入口。

每个页面都必须覆盖加载、空数据、失败、权限不足和小屏布局，不能只定义成功态。

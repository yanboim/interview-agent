# 页面清单

| 页面/界面 | 路由 | 主要内容 | 关键状态 |
|---|---|---|---|
| 身份覆盖层 | 产品工作区内 | 登录、注册、找回密码 | 初始、提交、错误、成功 |
| 今日训练 | `/today` | 目标、建议、提醒、快速入口 | 首次、空、加载、已配置 |
| AI问答 | `/chat/{sessionId?}` | 消息、输入、流式回答、来源 | 空、生成、冲突、取消、错误 |
| 会话历史 | `/history` | 搜索、日期分组、重命名、归档 | 空、筛选、批量操作 |
| 模拟面试 | `/interviews/{interviewId?}` | 配置、问题、回答、评分、进度 | 创建、答题、评分、完成、恢复 |
| 能力画像 | `/profile` | 综合分、维度、趋势、主题、薄弱点 | 空数据、筛选、正常 |
| 学习计划 | `/learning` | 任务、状态、到期日、复习 | 空、筛选、编辑、复习 |
| 设置 | 工作区弹窗 | 主题、账号和提醒相关设置 | 查看、保存、错误 |
| 管理后台 | `/admin` | 概览、用户、分析、审计、知识 | 未登录、加载、错误、危险操作 |

## 共用覆盖层

- 确认对话框：删除、归档或高风险操作；
- Toast：短时成功、失败和提醒；
- 恢复码对话框：只在生成时完整展示；
- 目标设置对话框：首次使用和主动修改；
- 全局错误边界：避免空白页并提供恢复入口。

每个页面都必须覆盖加载、空数据、失败、权限不足和小屏布局，不能只定义成功态。

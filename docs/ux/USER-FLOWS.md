# 用户流程

## 身份流程

```text
未认证
  ├── 注册成功 -> 产品工作区 -> 首次目标设置
  ├── 用户登录成功 -> 产品工作区
  ├── 管理员登录成功 -> 管理工作区
  └── 找回密码 -> 使用恢复码 -> 撤销旧会话 -> 重新登录
```

用户凭据不能登录管理员入口，管理员凭据不能进入产品工作区。

## 聊天流程

```text
选择/创建会话
  -> 输入校验
  -> 创建幂等键
  -> 领取会话生成权
  -> 流式事件
       ├── 文本片段
       ├── 来源
       ├── 完成
       └── 错误/取消
  -> 完成时原子写入正式历史
```

生成中再次提交显示“当前会话正在生成”；失败或取消后保留原输入和同一幂等键用于
安全重试。

## 面试流程

```text
配置主题/难度/题数 -> 开始 -> 显示题目
  -> 回答 -> 提交中 -> 评分反馈
  -> 下一题 ─────────────┐
  -> 完成 -> 报告 -> 能力画像/学习任务
```

用户返回未完成面试时，从服务端恢复当前题目。主动重答是新尝试，网络重试是同一
幂等命令，两者在文案和数据上不可混淆。

## 学习任务流程

```text
能力画像 -> 生成建议 -> 创建去重任务 -> 待开始/进行中/已完成
       -> 复习打卡 -> 更新下一次复习日期 -> 今日训练再次提醒
```

## 知识发布流程

```text
管理员选择文件 -> 保存 -> 发起导入 -> 排队/执行
  -> 候选集合 -> 结构验证 -> 回归门禁
  -> 成功切换别名 / 失败保留旧版本
  -> 状态页查看 -> 必要时回滚
```

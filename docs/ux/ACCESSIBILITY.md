# 可访问性规范

## 基线

- 核心流程支持键盘操作和可见焦点；
- 语义HTML优先，ARIA只用于补足语义；
- 文本和交互对比满足WCAG AA方向；
- 不依赖颜色、动画或声音单独表达信息；
- 支持桌面Chromium和Pixel 7尺寸，无非预期横向溢出。

## 交互

- 对话框打开后焦点进入，关闭后回到触发元素；
- Escape按预期关闭非破坏性覆盖层；
- 表单错误与输入关联并可被读屏识别；
- 流式更新使用不过度打断用户的实时区域；
- 加载、停止和禁用状态有可读名称；
- Markdown标题、列表、表格和链接保持语义。

## 验证

- 自动化axe不得出现critical或serious问题；
- 键盘手工走查登录、目标、聊天、面试、历史和确认框；
- 200%缩放和小屏不丢失核心操作；
- 动画尊重 `prefers-reduced-motion`；
- 自动检查不能替代读屏和键盘抽查。

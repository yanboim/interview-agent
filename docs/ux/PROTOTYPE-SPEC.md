# 低保真原型说明

- 状态：产品与研发基线
- 保真度：结构和交互，不定义最终视觉像素
- 页面来源：[页面清单](SCREEN-INVENTORY.md)

## 工作区框架

```text
┌──────────────┬─────────────────────────────────────────────┐
│ Logo/导航     │ 顶栏：当前位置、状态、设置、账号             │
│              ├─────────────────────────────────────────────┤
│ 今日训练      │                                             │
│ AI问答        │               当前功能面板                   │
│ 模拟面试      │                                             │
│ 能力画像      │                                             │
│ 学习计划      │                                             │
│ 历史          │                                             │
└──────────────┴─────────────────────────────────────────────┘
```

移动端侧栏折叠为可打开导航，主内容保持单列且不得横向溢出。

## 今日训练

```text
┌ 目标岗位 / 准备度 / 修改目标 ───────────────────────────────┐
├ 推荐下一步 ─────────┬ 到期复习 ─────────┬ 继续面试 ─────────┤
├ 薄弱点摘要 ────────────────────────────────────────────────┤
└ 最近训练与快速入口 ─────────────────────────────────────────┘
```

首次用户先展示目标设置，保存后立即刷新建议。无训练数据时用明确行动代替空图表。

## AI问答

```text
┌ 会话标题 / 新会话 ──────────────────────────────────────────┐
│ 用户消息                                                     │
│ 助手回答                                                     │
│ └ 来源卡片：文件/URL、标题、摘要、时间                       │
│ ...                                                          │
├ 输入框 ─────────────────────────────── [停止/发送] ─────────┤
└ 生成、重试或错误状态                                         ┘
```

流式文本逐步出现，来源以结构化区域展示。停止后保留输入恢复路径，不把未完成片段
伪装为正式完成答案。

## 模拟面试

```text
配置态：主题 | 难度 | 题数 | [开始]

答题态：
┌ 进度 2/5 ───── 主题/难度 ───────────────────────────────────┐
│ 问题正文                                                     │
│ 回答输入                                                     │
│ [提交答案]                                                   │
├ 评分：准确性 / 深度 / 结构 / 实践                            │
│ 反馈与改进建议                                               │
└ [下一题] [查看历史尝试]                                      ┘
```

提交期间锁定重复提交，但允许用户复制回答。并发冲突提示稍后重试，不清空内容。

## 能力画像与学习

画像顶部显示综合分、数据量和置信说明，下方依次为四维能力、趋势、主题表现、薄弱点
与优先行动。学习页面将行动呈现为可更新状态和复习日期的任务，而不是纯文本建议。

## 管理后台

```text
┌ 管理导航 ─────┬ 运行摘要 / 用户 / 分析 / 审计 / 知识库 ─────┐
│               │ 当前服务知识版本                            │
│               │ 候选与历史版本                              │
│               │ 文件和导入任务                              │
│               │ [导入] [回滚]                               │
└───────────────┴─────────────────────────────────────────────┘
```

发布与回滚显示目标版本、当前版本和操作影响。删除文件与切换知识版本是不同操作。

## 原型验收

- 所有核心任务不依赖隐藏导航；
- 成功、加载、空、错误、冲突、取消和权限状态有落点；
- 桌面和移动核心流程一致；
- 深链刷新能够恢复服务端资源；
- 危险操作需要明确目标和确认；
- 文案不把模型输出描述为客观招聘结论。

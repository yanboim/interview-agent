# 故障排查

## `/ready` 返回503

1. 查看返回的依赖类别，不公开传播内部详情。
2. 检查数据库连接和Alembic Revision。
3. 检查Qdrant服务及服务别名目标。
4. 配置Redis时检查Redis连接。
5. 检查最近配置、迁移或知识发布。

## 聊天/面试持续409

- 确认客户端是否复用同一幂等键和正文；
- 查询相应Turn状态和开始时间；
- 若是正常生成，遵守 `Retry-After`；
- 若进程崩溃留下 `generating`，保留证据并按批准恢复流程处理，不直接改库抢占。

## Worker任务不推进

- 检查Worker、Redis和队列配置；
- 在管理后台系统资源中心确认 Worker 心跳是否为“健康”；心跳超过
  `WORKER_HEARTBEAT_TTL_SECONDS` 未刷新时会显示“不可用”；
- 查看任务租约、所有者、尝试次数和下次执行时间；
- 检查Embedding、Qdrant和回归门禁错误；
- 不清空队列或删除候选来掩盖根因。

## RAG无结果或质量下降

- 确认服务别名和物理集合；
- 检查Embedding模型/维度与集合一致；
- 检查Dense阈值、候选K、最终K和重排开关；
- 运行版本化评估并比较最近知识/配置变化。

## 登录问题

- 区分产品和管理员入口；
- 检查Token是否因刷新、退出、改密或恢复被撤销；
- 检查系统时间和Token有效期；
- 不记录或复制完整Token到Issue。

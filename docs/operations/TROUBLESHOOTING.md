# 故障排查

## `/ready` 返回503

1. 查看返回的依赖类别，不公开传播内部详情。
2. 检查数据库连接和Alembic Revision。
3. 检查Qdrant服务及服务别名目标。
4. 配置Redis时检查Redis连接。
5. 检查最近配置、迁移或知识发布。

## 聊天/面试持续409

- 确认客户端是否复用同一幂等键和正文；
- 查询相应Turn状态和开始时间；
- 若是正常生成，遵守 `Retry-After`；
- 若进程崩溃留下 `generating`，保留证据并按批准恢复流程处理，不直接改库抢占。

## Worker任务不推进

- 检查Worker、Redis和队列配置；
- 在管理后台系统资源中心确认 Worker 心跳是否为“健康”；心跳超过
  `WORKER_HEARTBEAT_TTL_SECONDS` 未刷新时会显示“不可用”；
- 查看任务租约、所有者、尝试次数和下次执行时间；
- 检查Embedding、Qdrant和回归门禁错误；
- 不清空队列或删除候选来掩盖根因。

## RAG无结果或质量下降

- 确认服务别名和物理集合；
- 检查Embedding模型/维度与集合一致；
- 检查Dense阈值、候选K、最终K和重排开关；
- 运行版本化评估并比较最近知识/配置变化。

## Agent工作流停滞或重复确认

- 读取所属运行和步骤状态、输入摘要、领取所有者、尝试次数及安全错误，不复制正文；
- `awaiting_confirmation` 只允许当前用户确认原提案；改变输入必须创建新运行；
- claimed步骤只有超过恢复阈值才由管理员恢复，命令步骤确认已存结果后再重试；
- 重复确认应重放同一结果；若产生重复任务，停止恢复并按幂等性事故处理。

## 记忆、引用或反馈异常

- 后续回答未使用记忆时，确认状态为confirmed且来源仍存在、版本未过期；
- 纠正后的记忆必须重新确认，删除后不得继续出现在新快照；
- 引用缺失时检查证据ID、Prompt/Schema/模型版本和结构化输出错误，不手工补造来源；
- 反馈必须绑定当前用户已完成回合；负面候选在隐私评审前不得加入用户正文。

## 模型路由质量、延迟或成本回归

- 检查当前路由阶段、用途模型、请求预算、价格版本和Canary报告；
- Rollout放行时，多意图应进入有界Workflow V2路由且不得只执行其中一支；阶段off时
  才应进入保留的Supervisor，高影响用途不应使用未批准回退；
- 将阶段切回off恢复保留的默认路径，再比较分组质量、p95和单次完成成本；
- 不通过降低零容忍安全门禁或扩大预算掩盖回归。

## 简历长期停在处理中或导出失败

- 检查 `RESUME_FEATURE_ENABLED`、Worker心跳、任务状态和模型超时；
- 确认API与Worker可读取同一 `USER_FILES_DIR`，并检查文件权限和容量；
- 导出被拒绝时检查事实警告、待补充项和编辑版本冲突，不绕过事实门禁；
- 只重试失败命令，不重新上传同一文件制造重复资源。

## 面试复盘无法转写或分析

- 文本复盘无需转写配置；音频入口还要求转写功能开关、完整提供方配置和用户确认；
- 检查文件大小/格式、Worker心跳、转写超时和供应商限流；
- 确认逐字稿已保存且用户确认的是最新版本，编辑后旧确认会失效；
- 逐字稿持久化后检查临时音频删除；不要把音频或逐字稿复制到日志/Issue。

## 登录问题

- 区分产品和管理员入口；
- 检查Token是否因刷新、退出、改密或恢复被撤销；
- 检查系统时间和Token有效期；
- 不记录或复制完整Token到Issue。

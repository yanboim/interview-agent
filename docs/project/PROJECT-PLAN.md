# 项目计划

## 生命周期里程碑

| 阶段 | 主要交付 | 完成证据 |
|---|---|---|
| 产品基线 | 愿景、PRD、画像、旅程、指标 | 产品评审 |
| 原型 | 信息架构、流程、页面、交互 | 原型评审 |
| 架构 | 系统、领域、数据、Agent、RAG、安全 | 设计评审 |
| 实现 | 执行计划、代码、迁移、配置 | PR和聚焦测试 |
| 验证 | 契约、集成、E2E、AI和安全 | 质量门禁 |
| 发布 | 制品、备份、Canary、生产 | 发布记录 |
| 运营 | SLI、告警、事故、容量、恢复 | 运行证据 |
| 迭代 | 指标、反馈、复盘和风险 | 新一轮优先级 |

## 当前状态

基础产品和可靠性能力已实现并由功能契约跟踪；全生命周期文档正在建立。正式SLO、
RPO/RTO、法律隐私政策、高保真视觉和外部支持承诺需要责任人审批后计划。

每个新里程碑使用 `docs/exec-plans/active/` 的具体计划，不在本文件维护重复任务清单。

# 面试复盘页面 UI 优化

- 状态：completed
- 日期：2026-07-29
- 产品契约：`real-interview-transcription-review`

## Objective

将面试复盘页优化为清晰、紧凑、可扫描的双栏工作台，改善长篇整体总结、评分、
行动计划和数十道逐题复盘的阅读体验。

## Non-goals

- 修改复盘数据、评分或模型调用；
- 启用音频转写；
- 改变复盘创建、确认、删除和重试的业务行为。

## Acceptance criteria

- 页面使用现有有效设计 Token，卡片、边框、背景和表单样式在明暗主题均可用；
- 左栏明确区分新建入口、功能说明和历史记录，并显示中文状态；
- 整体复盘以摘要、四维评分、亮点/待提升和行动计划分区展示；
- 逐题复盘采用可折叠卡片，默认展开首题，长内容不挤压页面；
- 桌面端内容宽度合理，移动端改为单栏且无横向溢出；
- 原有复盘 E2E、无障碍、类型、构建和完整 Harness 通过；
- 使用浏览器验证页面内容、错误覆盖层、关键控件和桌面/移动端截图。

## Findings

- 原样式引用了未定义的 `--border`、`--surface`、`--accent` 等变量，关键边框、
  卡片背景和选中态声明被浏览器忽略，页面退化为接近无样式的文本流。
- 整体摘要与 48 道逐题复盘全部平铺，缺少视觉层级和渐进展开机制。
- 复盘样式从主应用 CSS 中拆为路由按需资源；主 CSS 为 116.86 KB，复盘专属
  CSS 为 10.71 KB，均通过现有 Bundle 门禁。

# Repository knowledge base

This directory contains versioned information that coding agents and reviewers
need to make and verify changes.

- `product-specs/`: machine-readable behavior and acceptance contracts.
- `design-docs/`: durable architectural decisions and design proposals.
- `exec-plans/`: active and completed implementation plans.
- `reliability/`: failure modes, SLOs, recovery, and operational runbooks.
- `security/`: trust boundaries, data handling, and security review notes.
- `generated/`: reproducible references generated from code or schemas.
- `tech-debt-tracker.md`: prioritized, owned architectural debt.

`AGENTS.md` is the short entry map. It should point here instead of duplicating
the detailed material.

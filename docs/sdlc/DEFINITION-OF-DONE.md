# 完成定义（DoD）

## 行为

- 验收条件全部满足；
- 当前与计划行为没有混写；
- 权限、所有权、重试、并发和失败恢复符合契约；
- 没有超出需求的无关变更。

## 实现

- 依赖方向符合架构；
- 新数据库结构具有Alembic迁移和历史数据策略；
- 外部调用有超时、错误、指标、预算和成本行为；
- 不引入秘密、生产数据或私人知识；
- 代码对当前和历史输入具有安全兼容性。

## 验证

- 聚焦测试通过；
- 适用的后端、前端、迁移、浏览器、可访问性、AI评估和安全检查通过；
- 仓库级变化通过 `make harness-check`；
- 无法执行的要求检查被明确报告；
- 功能契约只在有真实执行证据时标记为 `passing`。

## 文档与发布

- PRD、原型、架构、API、运行和安全文档按影响更新；
- 配置样例不包含真实秘密；
- 发布说明记录功能、修复、迁移、风险和回滚；
- 活动执行计划记录最终决定和验证并归档；
- 新的结构性限制进入技术债清单。

## 交付

- 评审意见已处理；
- 制品可复现且版本可追踪；
- 部署后验证和观测窗口明确；
- 相关负责人知道发布结果和残余风险。

# 后端工程规范

## 分层

- `app/main.py`只负责组合、Middleware、生命周期和静态路由；
- API Router负责HTTP校验、身份、状态码和序列化；
- 应用服务协调用例、外部调用和事务脚本；
- 纯领域模块不依赖FastAPI、SQLAlchemy、Redis、Qdrant或模型SDK；
- 基础设施适配器实现数据库、模型、检索和观测细节。

## 异步与阻塞

数据库使用同步SQLAlchemy Core，经共享 `SyncExecutor` 进入线程边界。Router不应
散布 `asyncio.to_thread`。模型或网络调用不在数据库事务内。

## 错误和输入

- 使用Pydantic验证HTTP结构；
- 对外错误稳定且不泄露提供方、SQL、路径、Token或私人正文；
- 为超大输入、冲突、限流和依赖未就绪使用明确状态码；
- 结构化模型输出必须验证，不能信任自由JSON。

## 正确性

- 用户资源查询必须含服务端身份；
- 可重试写使用幂等键、摘要、条件更新和持久结果；
- 跨实例正确性依赖数据库/Redis控制，不依赖Python进程锁；
- 外部调用具有超时、有限重试、预算、指标和安全错误。

## 测试

纯规则优先单元测试；应用服务测试并发、失败和重放；Storage测试事务与隔离；
Router测试身份和映射；Migration测试空库和历史回填。

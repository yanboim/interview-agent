# 威胁模型

## 资产

- 账号、密码摘要、访问和刷新令牌；
- 用户目标、JD、对话、面试回答、评分和学习记录；
- 训练记忆、Agent确认/运行、声明证据和用户反馈；
- 头像、简历原件/优化稿、真实面试音频、逐字稿和复盘；
- 私人知识文件、分块、向量和来源；
- 审计事件、执行追踪和部署发布证据；
- 管理员权限、应用/模型/Search API密钥；
- PostgreSQL、Redis、Qdrant、备份、日志和发布制品。

## 主要威胁与控制

| 威胁 | 示例 | 当前控制 |
|---|---|---|
| 身份伪造 | 伪造 `user_id`、复用撤销Token | 服务端Token身份、摘要存储、轮换撤销 |
| 越权 | 读取他人会话、用户调用管理接口 | 所有者过滤、角色校验、负向测试 |
| 篡改/重放 | 重复答案、重复聊天、任务重复执行 | 幂等键、内容摘要、条件领取、所有者Token |
| 信息泄露 | 错误/日志包含秘密或私人知识 | 安全错误映射、截断审计、秘密文件 |
| 拒绝服务 | 大输入、并发模型调用、请求洪泛 | 输入预算、并发限制、限流、超时 |
| 权限提升 | 普通账号登录管理面、模型调用危险工具 | 独立登录面、服务端RBAC、结构化工具 |
| 供应链 | 可变依赖/镜像、恶意包 | 哈希依赖、锁文件、镜像摘要、审计和扫描 |
| Prompt/内容注入 | 私人文档诱导工具越权 | 工具身份不来自模型、管理员操作不由模型直接执行 |
| 数据破坏 | 导入删除服务集合、错误恢复 | 候选版本、原子别名、显式恢复确认 |
| 恶意文件 | 路径穿越、伪造扩展名、超大简历/音频 | 服务端存储键、大小/MIME/签名校验、非静态访问 |
| 敏感外发 | 未同意即发送音频、Prompt包含多余正文 | 功能开关、逐次同意、数据最小化、供应商审批 |
| 管理员滥用 | 无目的浏览跨用户交互正文 | 管理RBAC、主动详情读取、请求审计和关联ID |
| 工具数据泄露 | 审计复制查询/结果正文，公开搜索携带PII或私人材料 | 内容最小化审计、确定性DLP、外发预览确认 |
| 检索指令注入 | 私人分块或网页片段伪装系统指令 | 明确不可信证据包装、结构化工具、注入回归集 |
| 未确认变更 | 模型直接创建任务或重放旧确认 | 所有者/内容绑定、过期、单次领取和存储结果重放 |
| 记忆污染 | 推断或旧来源事实进入后续上下文 | proposed/confirmed/rejected状态、来源版本和用户纠正/删除 |
| 证据伪造 | 回答引用不存在或不支持声明的来源 | 稳定证据ID、Schema校验、声明级支持状态和零容忍评估 |
| 模型回退漂移 | 高影响评分切换到未校准模型 | 按用途批准列表、分组门禁、阶段开关和即时回滚 |

## 高风险边界

### 外部模型

Prompt可能包含用户回答、历史摘要或检索正文。启用前确认提供方数据使用、保留和
区域要求；错误不回传提供方敏感正文。

音频转写额外要求功能开关、完整供应商配置和逐次显式同意。供应商说话人标签只映射
为 `unknown`，必须由用户确认；逐字稿持久化成功后才删除音频，失败时只为受控重试
或用户删除而保留。

### 公开搜索

默认关闭。查询在网络I/O前拒绝凭据、高熵Token、PII、简历/逐字稿或私人来源片段。
带私人上下文线索或过长的模糊查询只生成预览，当前所有者使用内容绑定确认后最多执行
一次；重复确认只重放存储结果。来源标记为公开，私人知识正文不拼入查询。

### Agent记忆与变更

只有用户确认且来源仍有效的训练记忆进入后续上下文。纠正使记忆重新待确认，删除立即
影响未来快照。学习任务等变更必须先预览再确认；跨用户、内容改变、过期或重复确认不
能再次执行效果。管理员运行检查不展示用户输入、提案或结果正文。

### 管理知识

文件名防路径穿越；普通用户无管理权限；发布先构建和验证候选；回滚只接受受管理
集合名称。

### 恢复与备份

备份包含高度敏感数据。恢复具有覆盖性，要求环境确认、批准、审计和恢复后验证。

## 未决风险

- 正式数据保留和用户导出/删除政策待批准；
- 生产入口TLS、WAF和网络策略由部署平台负责，仓库只能提供应用约束；
- 模型内容安全和评分偏差不能仅靠技术完全消除；
- 正式渗透测试和恢复目标需要独立计划。

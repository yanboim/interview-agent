# 隐私与数据处理说明

本文是工程数据处理基线，不替代面向用户的法律隐私政策。正式上线前应由业务和法律
负责人确认地区、主体权利、保留期和第三方条款。

## 收集的数据

- 账号和认证安全材料；
- 目标岗位、方向、JD和提醒偏好；
- 对话、面试问题/回答、评分、来源和学习任务；
- 产品事件、工具审计、错误和运行遥测；
- 管理员上传的私人知识文件及其索引。
- 用户上传的简历原件、解析文本、评估、优化稿和事实确认；
- 真实面试音频、逐字稿、说话人修正和复盘报告。

## 使用目的

- 提供认证和用户数据隔离；
- 生成问答、模拟面试、评分、能力画像和学习计划；
- 恢复历史和支持安全重试；
- 管理知识发布、诊断故障、保护系统和改进产品质量。

## 第三方处理

- Chat模型可能接收Prompt、回答、历史摘要和选定知识上下文；
- Embedding服务接收知识分块或查询；
- 启用LLM重排时，模型接收候选知识正文；
- 启用公开搜索时，Search提供方接收查询；
- 观测平台接收经最小化的运行数据。

公开搜索和LLM重排默认关闭。提供方、目的、数据范围和保留要求应在生产配置审批中
记录。

启用音频转写时，系统只把用户明确确认的音频发送给单独配置的转写提供方。生产启用
前必须记录提供方、地区、传输、保留、删除、超时和成本条款；未配置或未确认时不得
外发。文本逐字稿不依赖音频转写提供方。

## 最小化与安全

- 只发送完成请求所需上下文；
- 使用上下文预算和摘要限制历史；
- 不在日志和指标中记录完整正文或秘密；
- 使用服务端身份、角色和资源所有权；
- Secret通过环境或文件挂载，Token只保存摘要；
- 备份和恢复遵守Restricted/Confidential处理要求。

## 保留、导出与删除

用户目前可以删除其会话、面试和学习任务；Token可被撤销。完整账号删除、数据导出、
日志/备份保留期限和第三方删除请求尚需产品化和正式政策。批准前不得承诺具体期限或
自动删除能力。

简历与复盘采用以下产品级最小化规则：

- 简历原件保留到用户删除简历；
- 面试音频只为转写和失败重试暂存，逐字稿成功持久化后删除；
- 逐字稿和复盘保留到用户删除复盘记录；
- 删除和备份策略必须覆盖数据库、用户文件卷、日志和第三方副本。

## AI透明度

模型回答和评分可能不准确或存在偏差。产品应展示来源和评分维度，并明确其用于训练
辅助而非招聘决定。用户应能重试、重答和查看历史依据。

## 管理员交互内容访问

管理员审计中心可为运维调查展示聊天和面试的权威业务内容。完整内容仍保留在所属业务
表中，不复制到通用审计或追踪表。

- 管理员读取交互或执行链路也会产生审计事件；
- 审计和追踪详情会脱敏密码、Token、Authorization、Secret、Prompt、消息、回答和
  正文类字段；
- 用户正文不得复制到普通日志、指标标签或遥测属性；
- 工具追踪只保存有界摘要和关联标识，不保存凭据或完整私有知识块；
- 账号/数据删除和保留流程必须覆盖权威交互记录，审计保留策略单独管理。

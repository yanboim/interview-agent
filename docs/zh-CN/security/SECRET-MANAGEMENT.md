# 密钥管理

## 范围

模型、Embedding、公开搜索、应用API Key、数据库凭据、Grafana管理员凭据、部署和
GitHub凭据均为Restricted。

## 生命周期

1. 由批准的Secret管理系统生成或导入。
2. 只分发给需要的环境和服务身份。
3. 通过环境或 `*_FILE` 挂载，不写入镜像和仓库。
4. 日志、错误、指标、Trace和文档不回显。
5. 定期及人员/供应商变化时轮换。
6. 不再使用时撤销并验证旧值失效。

## 泄露响应

- 立即限制访问和保留证据；
- 轮换秘密并撤销相关Token/会话；
- 检查Git历史、日志、制品、缓存和第三方系统；
- 不只删除当前文件中的字符串；
- 进入安全事故响应并记录影响。

`.env.example`只保存字段名和不可用占位符。真实 `.env` 不提交。

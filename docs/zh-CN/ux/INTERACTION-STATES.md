# 交互状态契约

| 状态 | UI行为 | 用户可执行动作 |
|---|---|---|
| 初始 | 展示任务目的和主要入口 | 开始、设置目标或选择历史 |
| 加载 | 保持布局稳定，说明正在加载什么 | 等待；非关键区域可返回 |
| 空数据 | 解释为什么为空并给出下一步 | 创建、训练、生成任务 |
| 提交中 | 防止同一动作重复触发 | 必要时取消或离开 |
| 流式生成 | 展示增量内容和停止按钮 | 停止；不可并发发送 |
| 并发冲突 | 保留输入，说明已有请求进行中 | 稍后同键重试 |
| 可重试错误 | 保留原命令内容与幂等键 | 重试或返回 |
| 不可重试错误 | 说明校验、权限或内容问题 | 修改输入或重新登录 |
| 取消 | 说明未形成正式完成结果 | 同内容重新生成 |
| 权限不足 | 不展示敏感资源详情 | 返回授权范围内页面 |
| 成功 | 更新服务端权威数据并提供下一步 | 继续、查看报告、复习 |
| 异步排队（规划） | 显示当前阶段并允许离开，刷新后从服务端恢复 | 返回列表、稍后查看 |
| 事实待确认（规划） | 标记无来源事实和待补充项，阻止正式导出 | 编辑、删除或确认来源 |
| 逐字稿待确认（规划） | 展示片段和说话人，不生成评分 | 编辑、合并、拆分、确认 |
| 编辑版本冲突（规划） | 保留本地修改并提示服务器已有新版本 | 重新加载、对比后再保存 |

## 通用规则

- 不用单一颜色表达状态；同时提供文字或图标语义。
- 错误消息不暴露提供方正文、Token、SQL、路径或私人知识。
- 删除、永久覆盖或生产恢复需要明确确认。
- 失败后不清空可以安全修正或重试的用户输入。
- 重试必须区分网络重放与主动创建新业务尝试。
- Toast只用于短反馈；需要决策或恢复的错误保留在任务上下文中。
- 音频外发确认、事实警告和逐字稿确认不得使用预先勾选的同意框。

# 低保真原型说明

- 状态：产品与研发基线
- 保真度：结构和交互，不定义最终视觉像素
- 页面来源：[页面清单](SCREEN-INVENTORY.md)

## 工作区框架

```text
┌──────────────┬─────────────────────────────────────────────┐
│ Logo/导航     │ 顶栏：当前位置、状态、设置、账号             │
│              ├─────────────────────────────────────────────┤
│ 今日训练      │                                             │
│ AI问答        │               当前功能面板                   │
│ 模拟面试      │                                             │
│ 简历中心      │                                             │
│ 面试复盘      │                                             │
│ 能力画像      │                                             │
│ 学习计划      │                                             │
│ 历史          │                                             │
└──────────────┴─────────────────────────────────────────────┘
```

移动端侧栏折叠为可打开导航，主内容保持单列且不得横向溢出。

## 今日训练

```text
┌ 目标岗位 / 准备度 / 修改目标 ───────────────────────────────┐
├ 推荐下一步 ─────────┬ 到期复习 ─────────┬ 继续面试 ─────────┤
├ 薄弱点摘要 ────────────────────────────────────────────────┤
└ 最近训练与快速入口 ─────────────────────────────────────────┘
```

首次用户先展示目标设置，保存后立即刷新建议。无训练数据时用明确行动代替空图表。

## AI问答

```text
┌ 会话标题 / 新会话 ──────────────────────────────────────────┐
│ 用户消息                                                     │
│ 助手回答                                                     │
│ └ 来源卡片：文件/URL、标题、摘要、时间                       │
│ ...                                                          │
├ 输入框 ─────────────────────────────── [停止/发送] ─────────┤
└ 生成、重试或错误状态                                         ┘
```

流式文本逐步出现，来源以结构化区域展示。停止后保留输入恢复路径，不把未完成片段
伪装为正式完成答案。

## 模拟面试

```text
配置态：主题 | 难度 | 题数 | [开始]

答题态：
┌ 进度 2/5 ───── 主题/难度 ───────────────────────────────────┐
│ 问题正文                                                     │
│ 回答输入                                                     │
│ [提交答案]                                                   │
├ 评分：准确性 / 深度 / 结构 / 实践                            │
│ 反馈与改进建议                                               │
└ [下一题] [查看历史尝试]                                      ┘
```

提交期间锁定重复提交，但允许用户复制回答。并发冲突提示稍后重试，不清空内容。

## 能力画像与学习

画像顶部显示综合分、数据量和置信说明，下方依次为四维能力、趋势、主题表现、薄弱点
与优先行动。学习页面将行动呈现为可更新状态和复习日期的任务，而不是纯文本建议。

## 简历中心

```text
┌ 简历列表 ─────────┬ 处理状态 / 目标岗位 / JD版本 ───────────┐
│ [上传简历]        │ 匹配度与分项评分                         │
│ 简历A · 已完成    │ 问题 -> 原文证据 -> 改写建议             │
│ 简历B · 处理中    │                                           │
│                   ├ 完整优化稿 ─────────────────────────────┤
│                   │ [编辑] [预览] [导出DOCX]                 │
└───────────────────┴───────────────────────────────────────────┘
```

事实警告和待补充项固定显示在优化稿附近。存在未解决项时导出按钮保持不可用并说明
原因。异步处理允许用户离开页面，返回或刷新后从服务端恢复状态。

## 面试复盘

```text
输入态：音频 + 外发确认 / 文本逐字稿 -> [开始处理]

确认态：
┌ 逐字稿版本 / 保存状态 ──────────────────────────────────────┐
│ 00:05 面试官  [说话人▼] 问题文本                            │
│ 00:18 候选人  [说话人▼] 回答文本                            │
│ [拆分] [与上一段合并]                                       │
└──────────────────────────────────── [确认并生成复盘] ───────┘

报告态：
┌ 整体摘要 / 来源：真实面试 ──────────────────────────────────┐
├ 逐题：问题 / 回答 / 四维评分 / 遗漏 / 改进回答              │
└ 行动计划 -> [生成学习任务]                                  │
```

自动说话人未知时不得默认标记为候选人。修改已确认逐字稿后，报告入口重新回到待确认
状态。

## 管理后台

```text
┌ 管理导航 ─────┬ 运行 / 资源 / 用户 / 审计 / 发布 / 知识库 ──┐
│               │ API、数据库、Redis、Qdrant、Worker状态       │
│               │ 请求审计、用户交互与执行链路                 │
│               │ 环境发布结果与回滚证据                       │
│               │ 知识文件、候选版本和当前版本                 │
└───────────────┴─────────────────────────────────────────────┘
```

发布与回滚显示目标版本、当前版本和操作影响。删除文件与切换知识版本是不同操作。
交互正文只在管理员主动检查时从权威业务表读取，列表默认展示最小化摘要。

## 原型验收

- 所有核心任务不依赖隐藏导航；
- 成功、加载、空、错误、冲突、取消和权限状态有落点；
- 桌面和移动核心流程一致；
- 深链刷新能够恢复服务端资源；
- 危险操作需要明确目标和确认；
- 文案不把模型输出描述为客观招聘结论。

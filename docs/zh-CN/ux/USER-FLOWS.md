# 用户流程

## 身份流程

```text
未认证
  ├── 注册成功 -> 产品工作区 -> 首次目标设置
  ├── 用户登录成功 -> 产品工作区
  ├── 管理员登录成功 -> 管理工作区
  └── 找回密码 -> 使用恢复码 -> 撤销旧会话 -> 重新登录
```

用户凭据不能登录管理员入口，管理员凭据不能进入产品工作区。

## 聊天流程

```text
选择/创建会话
  -> 输入校验
  -> 创建幂等键
  -> 领取会话生成权
  -> 流式事件
       ├── 文本片段
       ├── 来源
       ├── 完成
       └── 错误/取消
  -> 完成时原子写入正式历史
```

生成中再次提交显示“当前会话正在生成”；失败或取消后保留原输入和同一幂等键用于
安全重试。

## 面试流程

```text
配置主题/难度/题数 -> 开始 -> 显示题目
  -> 回答 -> 提交中 -> 评分反馈
  -> 下一题 ─────────────┐
  -> 完成 -> 报告 -> 能力画像/学习任务
```

用户返回未完成面试时，从服务端恢复当前题目。主动重答是新尝试，网络重试是同一
幂等命令，两者在文案和数据上不可混淆。

## 简历评估流程

```text
选择PDF/DOCX + 可选JD -> 校验并上传 -> 解析/分析
  -> 查看评分、证据、问题和建议
  -> 采纳/拒绝/编辑完整优化稿
  -> 解决事实警告和待补充项
  -> 网页预览 -> 导出DOCX
```

处理失败保留资源和安全重试入口。编辑冲突不覆盖服务器最新版本。删除简历前明确
说明历史模拟面试不会随之删除。

## 简历定向模拟面试流程

```text
配置面试 -> 选择通用或已完成简历分析
  -> 保存最小化上下文快照 -> 开始现有文字面试
  -> 简历项目/JD差距追问 -> 评分/报告 -> 能力画像/学习任务
```

未完成、已删除或不属于当前用户的简历分析不能用于开始面试。

## 面试复盘流程

```text
音频 + 外发确认 / 文本逐字稿
  -> 转写或文本分段 -> 等待用户确认
  -> 编辑文本和说话人 -> 确认最新版本
  -> 异步分析 -> 逐题与整体报告
  -> 真实来源能力画像/学习任务
```

自动转写后不直接评分。逐字稿修改会使旧确认失效；音频只在逐字稿成功持久化后
删除。

## 学习任务流程

```text
能力画像 -> 生成建议 -> 创建去重任务 -> 待开始/进行中/已完成
       -> 复习打卡 -> 更新下一次复习日期 -> 今日训练再次提醒
```

## 知识发布流程

```text
管理员选择文件 -> 保存 -> 发起导入 -> 排队/执行
  -> 候选集合 -> 结构验证 -> 回归门禁
  -> 成功切换别名 / 失败保留旧版本
  -> 状态页查看 -> 必要时回滚
```

## 管理员调查与发布核验流程

```text
管理员登录 -> 系统资源中心确认依赖和Worker心跳
  -> 按请求ID/用户/结果筛选审计事件
  -> 必要时读取权威聊天或面试内容并关联执行链路
  -> 核对部署发布台账中的环境、版本、结果和验证证据
```

读取跨用户交互内容本身产生审计事件；执行追踪只保存安全元数据，不复制Prompt、
回答、凭据或私人知识正文。

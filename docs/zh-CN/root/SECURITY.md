# 安全策略

## 报告方式

请将疑似漏洞私下报告给仓库维护者，或项目负责人配置的私有安全渠道。不要创建包含
凭据、利用步骤、私人知识、用户数据、数据库内容或未公开漏洞细节的公开Issue。

报告应包含：

- 受影响版本或Commit；
- 环境和前置条件；
- 不使用真实用户数据的最小复现；
- 实际行为与预期行为；
- 潜在影响；
- 已知的安全缓解措施。

## 响应方式

维护者应确认收到报告、限制证据访问、评估严重程度、保全日志、轮换已暴露Secret、
准备经过验证的修复并协调披露。在负责人和支持政策正式批准前，本项目不承诺固定响应
时限。

安全架构、威胁模型、数据分级和测试指南统一收录在
[`docs/security/README.md`](../security/README.md)。

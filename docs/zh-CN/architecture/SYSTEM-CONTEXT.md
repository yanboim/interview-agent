# 系统上下文

## 参与者与外部系统

```text
产品用户 ───────┐
系统管理员 ─────┼──> Interview Agent
运维维护者 ─────┘        │
                         ├──> Zhipu Chat / Embedding API
                         ├──> 可选音频转写服务
                         ├──> 可选公开搜索服务
                         ├──> PostgreSQL / SQLite
                         ├──> Redis
                         ├──> Qdrant
                         └──> Prometheus / OpenTelemetry / Grafana
```

## 系统职责

Interview Agent负责：

- 认证身份和用户数据所有权；
- 对话、面试、能力和学习业务状态；
- 头像、简历评估、事实受控优化稿、真实面试逐字稿与复盘；
- Agent工具编排和模型调用策略；
- 私人知识导入、检索、版本发布和来源元数据；
- 管理员操作、审计、运行状态和后台任务；
- HTTP、流式事件和前端工作区。

外部模型不负责身份、授权、业务提交或持久化决策。Qdrant不决定用户资源权限；
向量检索只在应用确认请求上下文后执行。

## 信任边界

| 边界 | 不可信输入 | 控制 |
|---|---|---|
| 浏览器 → API | Token、用户ID、正文、文件、幂等键 | 认证、所有权、格式/大小/签名校验、限流 |
| API → 模型 | Prompt、历史、检索上下文 | 预算、超时、安全错误、数据审批 |
| Worker → 转写服务 | 用户确认的面试音频 | 功能开关、显式同意、超时、最小化和供应商审批 |
| API → 搜索 | 用户查询 | 默认关闭、秘密检测、来源标记 |
| Worker → Qdrant | 文档和向量 | 候选版本、结构/回归门禁、原子别名 |
| API/Worker → 用户文件卷 | 头像、简历、临时音频 | 服务端存储键、共享持久卷、认证下载、生命周期清理 |
| 运维 → 数据 | 迁移、恢复、回滚目标 | 环境审批、显式确认、审计与验证 |

详细威胁见[威胁模型](../security/THREAT-MODEL.md)。

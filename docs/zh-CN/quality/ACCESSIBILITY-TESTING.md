# 可访问性测试

## 自动化

- Playwright在桌面和移动视口运行axe；
- critical和serious违规阻断；
- 检查横向溢出、可见焦点和关键控件；
- 组件测试覆盖Markdown语义和状态组件。

## 手工检查

- 仅键盘完成登录、设置目标、聊天、面试和确认；
- 焦点顺序与视觉顺序一致；
- 对话框焦点进入、限制和恢复；
- 读屏能理解表单标签、错误、流式状态和评分；
- 200%缩放和减少动画偏好可用；
- 浅色/深色主题对比清楚。

## 缺陷

可访问性缺陷按用户任务影响而不是只按工具级别排序。修复应增加可重复的浏览器或
组件证据，避免仅在一个页面打补丁。

# 安全测试

## 自动化范围

- 用户/管理员登录面隔离；
- Token轮换、撤销、改密和恢复；
- 跨用户读取、修改、删除和领取；
- 安全文件名和路径穿越；
- 幂等键重放、不同正文和并发竞争；
- Secret文件读取和错误脱敏；
- Python/npm依赖审计；
- 容器高危/严重漏洞扫描；
- Markdown净化和前端不可信内容。

## 评审测试

- 威胁模型和数据流变化；
- 新外部提供方、Tool或管理员操作；
- CORS、TLS、Host、Ingress和私有网络；
- 备份访问、恢复确认和日志权限；
- Prompt注入不能改变工具身份和授权。

## 生产前

对公网入口、身份、会话、RBAC、速率限制和配置执行独立安全评审。正式渗透测试需
明确授权、范围、窗口和数据处理，禁止对未授权生产目标试探。

发现漏洞时使用私有报告渠道，不把Token、利用细节或用户数据放入公开Issue。

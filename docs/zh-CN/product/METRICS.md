# 产品指标

## 原则

- 指标用于理解训练闭环，不用于替代用户研究或形成招聘判断。
- 口径必须说明事件、主体、窗口和去重方式。
- 不在指标标签中放置用户输入、JD、对话或知识正文。
- 目标值只有在基线测量和负责人批准后填写；本文件不虚构当前目标。

## 核心漏斗

| 阶段 | 建议口径 | 当前数据来源 |
|---|---|---|
| 激活 | 注册后完成目标设置的独立用户 | 用户资料、产品事件 |
| 首训 | 激活后完成一次问答、面试或复习 | 消息、面试回合、学习任务 |
| 面试完成 | 已完成面试 / 已开始面试 | `interviews` |
| 简历价值 | 查看已完成分析或导出优化稿的用户 / 上传简历用户 | `resume_documents`、`resume_analyses`、产品事件 |
| 复盘完成 | 已完成报告 / 已创建复盘 | `interview_reviews` |
| 反馈使用 | 查看报告或画像的训练用户 | 产品事件 |
| 学习转化 | 创建学习任务的薄弱点用户 | `learning_tasks` |
| 复习留存 | 7/30天内再次训练或复习的用户 | 业务表和产品事件 |

## 质量与可靠性

- 聊天/面试完成率、失败率、取消率；
- 幂等重放率和并发冲突率；
- 首个流式事件时间、完整生成时间；
- RAG低相关拒绝率、引用覆盖率、nDCG/MRR；
- Agent路由总体与分Agent准确率；
- 知识发布成功率、回滚次数和任务重试次数；
- 简历解析/分析成功率、事实警告率、DOCX导出成功率；
- 音频转写/复盘成功率、逐字稿修订率和分批分析失败率；
- Worker心跳可用率、发布台账记录成功率和管理员调查请求失败率；
- 模型输入/输出Token、调用成本和预算拒绝。

## 指标治理

新增指标必须定义名称、目的、计算、维度、保留期和负责人，并检查隐私与基数。
Dashboard只能展示已定义口径；改变事件语义时同步更新PRD、埋点、查询和验收测试。

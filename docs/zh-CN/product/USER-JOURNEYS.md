# 用户旅程

## 首次使用

```text
进入产品 -> 注册/登录 -> 设置目标岗位与方向 -> 查看今日训练
        -> 选择问答、面试或学习任务 -> 获得反馈 -> 返回今日训练
```

成功条件：账号建立、目标按账号持久化、用户看到明确下一步。失败时保留已成功的
账号状态，不把管理员登录与产品登录混在同一流程。

## 知识问答

```text
进入聊天 -> 创建或恢复会话 -> 输入问题 -> 生成中
       -> 流式答案 + 来源 -> 历史持久化 -> 可搜索/重命名/归档
```

异常分支：

- 输入超出上下文预算：提交前拒绝并保留输入；
- 同一会话已有生成：返回冲突，稍后重试；
- 模型失败：记录失败回合，不加入孤立的正式用户消息；
- 连接取消：记录取消状态，同键同内容可重新生成；
- 已完成请求重试：直接重放持久化结果。

回答完成后，重要声明展示证据或“暂无证据支持/证据冲突”状态。用户可点赞或点踩；
反馈绑定当前用户和持久回合，删除反馈不改变权威聊天历史。

## 训练记忆

```text
设置 -> 新建事实/偏好/目标提议 -> 确认或拒绝
    -> 后续Agent上下文只读取已确认记忆
    -> 纠正 -> 回到待确认 -> 再次确认 / 删除
```

来源派生记忆在来源缺失或过期时不进入上下文。删除记忆立即影响下一次Agent调用，
但不删除原始聊天或面试记录。

## 模拟面试

```text
选择主题/难度/题数 -> 生成首题 -> 回答 -> 评分与反馈
                  -> 下一题或完成 -> 报告 -> 能力画像/学习任务
```

异常分支：

- 页面关闭：重新进入相同面试恢复服务端题目；
- 重复提交：同一幂等键重放原结果；
- 并发提交：只允许一个请求执行评分；
- 模型失败：同一键和答案可安全重试；
- 用户主动重答：形成新的回答尝试，但不伪装成网络重试。

## 学习与复习

```text
查看能力画像 -> 识别薄弱维度 -> 生成学习任务
            -> 开始/完成 -> 到期复习 -> 更新下一次复习时间
```

同一活跃薄弱点不重复创建任务。复习保存回忆结果与主观难度，并据此调整有界间隔。
任务和复习记录只属于当前认证用户。

## 个性化训练计划Agent

```text
学习页 -> 生成训练计划预览 -> 等待确认
      -> 取消 / 确认一次 -> 原子创建去重任务
      -> 查看步骤事件 -> 完成并进入现有模拟面试入口
```

确认前不产生业务变更。并发确认、网络重试或Worker恢复复用同一命令和已存结果；
跨用户访问、改变幂等输入和过期领取均被拒绝或安全恢复。

## 简历评估与定向面试

```text
上传PDF/DOCX -> 文件校验 -> Worker解析/分析 -> 查看证据和问题
             -> 编辑优化稿 -> 解决事实警告 -> 导出DOCX
             -> 选择分析版本 -> 简历定向模拟面试 -> 报告/能力/学习
```

扫描PDF、伪装类型、损坏或超限文件返回安全错误。处理失败可以使用同一命令重试；
编辑冲突不会覆盖较新版本。简历删除后不能再创建定向面试，但既有历史保留最小化
来源说明。

## 真实面试复盘

```text
文本逐字稿 --------------------------┐
音频 + 外部处理明确同意 -> 异步转写 ├-> 编辑片段/说话人
                                    -> 确认最新版本 -> 分批分析
                                    -> 整体/逐题报告 -> 能力/学习
```

未知说话人或没有候选人回答时不能分析。修改已确认逐字稿会清除旧确认和旧报告。
转写成功后删除音频；失败时保留以支持受控重试，用户删除会清理全部派生数据。

## 管理员知识发布

```text
管理员独立登录 -> 保存/选择知识文件 -> 创建导入任务
              -> Worker构建候选版本 -> 结构与检索验证
              -> 原子切换别名 -> 查看状态或回滚
```

上传、验证或切换失败时，正在服务的知识版本保持不变。回滚只切换别名，不删除
离开的版本。

## 管理员运行与审计

```text
管理员独立登录 -> 系统资源/Worker心跳/发布历史
              -> 活动筛选 -> 权威交互详情 -> 请求关联执行时间线
```

跨用户内容来自聊天和面试权威表，不复制到通用审计记录；查看内容和执行链路本身
产生审计事件。部署历史只接受部署执行器使用稳定ID写入的脱敏结果。

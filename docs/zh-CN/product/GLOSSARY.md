# 术语表

| 术语 | 定义 |
|---|---|
| 会话（Conversation） | 一个用户拥有的连续聊天容器，由稳定 `session_id` 标识 |
| 消息（Message） | 已完成并进入正式聊天历史的用户或助手内容 |
| 聊天回合（Chat Turn） | 一次可重试的生成命令，具有幂等和生命周期 |
| 面试（Interview） | 主题、难度、题数和状态组成的一次模拟训练 |
| 面试回合（Interview Turn） | 一道题及其答案、评分、反馈和提交状态 |
| 回答尝试（Answer Attempt） | 用户主动重答产生的历史版本，不等于网络重试 |
| 幂等键 | 标识同一逻辑命令的客户端键，用于安全重放 |
| 领取/Claim | 数据库或Redis条件操作，授予一个所有者执行命令的权利 |
| 所有者令牌 | 防止过期或竞争执行者提交结果的随机身份 |
| 能力画像 | 从当前用户已评分面试派生的跨场次读取模型 |
| 学习任务 | 由薄弱维度或问题转化的可执行和可复习行动 |
| 私人知识 | 管理员维护、不得默认公开或发送给搜索服务的知识内容 |
| 分块（Chunk） | 从知识文件切分并带稳定ID和标题上下文的检索单元 |
| 服务别名 | 指向当前Qdrant物理知识版本的稳定名称 |
| 候选版本 | 尚未通过全部发布验证的物理知识集合 |
| RAG | 检索相关知识并将其作为模型回答上下文的流程 |
| Agent | 基于模型选择专用能力或工具的编排层，不拥有授权决定 |
| 功能契约 | 记录产品行为状态、验收步骤和执行证据的机器可读文件 |
| Canary | 使用同一候选制品在有限范围内进行生产等价验证 |
| 简历分析 | 对一个用户简历版本和岗位/JD快照形成的结构化评估与优化稿 |
| 事实警告 | 优化稿中缺少原简历证据的新增事实或待补充项，会阻止导出 |
| 简历定向面试 | 使用不可变最小简历上下文快照出题的文字模拟面试 |
| 面试复盘 | 对已发生面试的确认逐字稿进行逐题和整体训练分析 |
| 逐字稿版本 | 每次文本、片段或说话人修改后递增的乐观并发版本 |
| 部署发布账本 | 由部署执行器写入、按稳定ID幂等更新的环境发布事实记录 |
| Worker心跳 | Redis中有界TTL的新鲜度信号，用于判断至少一个Worker是否在线 |

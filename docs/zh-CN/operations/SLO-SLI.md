# SLI、SLO与错误预算

## 当前状态

仓库具备请求、依赖、模型、Agent和任务观测，但尚未基于生产基线批准正式SLO、
错误预算、RPO或RTO。下列是待测量的SLI定义，不是现有SLA承诺。

## 建议SLI

| SLI | 计算方向 |
|---|---|
| API可用性 | 非预期5xx请求 / 有效请求 |
| 就绪性 | 可接流量实例时间 / 总时间 |
| 聊天成功 | 完成聊天回合 / 已领取回合 |
| 面试成功 | 完成答案提交 / 已领取提交 |
| 首包延迟 | 提交至首个文本事件 |
| 完成延迟 | 提交至终态 |
| 依赖健康 | 数据库、Redis、Qdrant、模型成功率与延迟 |
| 任务新鲜度 | 入队至成功/终态时间 |
| 知识发布 | 成功发布 / 有效发布尝试 |

## 批准流程

1. 收集至少一个代表性周期的基线。
2. 按用户旅程和依赖分解。
3. 产品、工程和运维批准目标与测量窗口。
4. 定义错误预算消耗、告警和发布冻结规则。
5. 每个季度或重大架构变化后复审。

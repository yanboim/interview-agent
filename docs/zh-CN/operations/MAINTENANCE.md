# 维护计划

| 周期 | 检查 |
|---|---|
| 每日 | 健康、错误、任务积压、模型异常、磁盘 |
| 每周 | 备份结果、失败任务、知识版本、依赖告警 |
| 每月 | 恢复抽查、容量趋势、Secret/权限审查、依赖更新 |
| 每季度 | 灾备演练、SLO复审、威胁模型、数据保留、成本 |
| 每次发布 | Migration、制品、Canary、回滚和发布后观察 |

维护动作记录环境、对象、负责人、批准、开始/结束、结果和回滚。需要停机或覆盖数据
的操作在维护窗口执行。

## 本地工作区产物

本地运行数据库、临时 Trace、测试截图和一次性诊断产物优先放在已忽略的 `.var/`；
兼容路径 `data/`、`backups/` 和 `test-results/` 仍保持忽略。在清理前先只读列出目标：

```bash
find .var data backups test-results -maxdepth 2 -type f -print
```

仓库不提供自动递归删除命令。数据库、备份、截图、Trace 和用户文件可能仍用于恢复、
审计或故障分析；删除前必须确认准确路径、保留期限、备份/恢复状态和数据负责人批准。
需要迁移旧路径时另立执行计划，先复制和校验，再由操作员显式确认切换及旧副本删除。

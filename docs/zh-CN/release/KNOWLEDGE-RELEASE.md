# 知识库发布

## 输入

- 已批准的知识文件；
- 当前Embedding、分块、检索和回归配置；
- 稳定服务别名和版本前缀；
- Redis发布锁和Worker可用。

## 发布

1. 以幂等键创建知识导入任务。
2. Worker领取并续租任务。
3. 创建新物理集合并上传分块。
4. 验证结构、数量和向量参数。
5. 运行配置的检索回归门禁。
6. 原子切换服务别名。
7. 确认新版本、缓存命名空间和检索冒烟。

失败候选不得影响原服务版本。回滚只切换到存在的受管理版本，不删除离开的集合。

## 记录

保存文件版本、任务ID、物理集合、Embedding模型、评估报告、切换时间和操作者。
历史版本清理单独审批。

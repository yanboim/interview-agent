# 前端工程规范

## 结构

- Router定义稳定深链；
- Store负责领域状态和API协调；
- `api/`负责协议、认证和流式解析；
- `components/ui/`提供基础组件；
- `components/app/`和`components/admin/`承载领域界面；
- 服务端是业务事实来源，Local Storage只保存令牌或设备偏好。

## TypeScript与状态

- API请求/响应有显式类型；
- 不用 `any` 绕过协议变化；
- 异步操作记录加载、失败和可重试状态；
- 幂等键在不确定失败中复用，正文改变后重新生成；
- 组件卸载和流式取消显式清理资源。

## 组件与样式

- 基础交互优先复用共享组件；
- 领域组件保持单一任务，避免在顶层View堆积业务逻辑；
- 样式使用领域文件和共享Token；
- 新页面覆盖桌面、小屏、键盘、空和错误状态。

## 安全

- Markdown经过净化；
- 不使用 `v-html` 展示不可信内容，除非经过统一安全管道；
- 不在浏览器存放服务API Key或管理员能力；
- 客户端权限隐藏不是服务端授权替代。

测试和关键浏览器旅程。

# 安全评审清单

## 触发

身份/RBAC、管理员功能、新外部服务、文件处理、数据导出/删除、支付、公开API、
网络暴露、Secret、备份/恢复或模型工具变化必须安全评审。

## 检查

- 资产、角色、所有者和信任边界；
- 输入、输出、错误和日志；
- 认证、授权和跨用户负向场景；
- 重放、并发、资源耗尽和滥用；
- 第三方数据范围、目的、保留和区域；
- Secret生命周期和最小权限；
- 迁移、备份、删除和恢复；
- 依赖、镜像和供应链；
- 测试证据、监控、告警和应急措施。

## 结论

记录范围、发现、严重度、负责人、截止、接受风险和重新评审触发。未解决高风险不应
通过关闭测试或隐藏界面绕过。

# Changelog

All notable user-visible and operational changes are recorded here. Dates use
UTC. The project has not yet adopted a formal semantic-version release history,
so entries are grouped by repository milestone.

## Unreleased

- Synchronize lifecycle documentation with the resume, interview-review,
  administrator observability, Worker heartbeat, and release-ledger features.

## 2026-07-29

- Add resume assessment, fact-controlled optimization, DOCX export, and
  resume-grounded mock interviews.
- Add text/audio real-interview transcription review with confirmed speaker
  roles, long-transcript batching, capability aggregation, and learning input.
- Add purpose-specific long-running model timeout policies for resume and
  interview-review jobs.

## 2026-07-28

- Add profile avatars and accessible reminder controls.
- Add administrator system resources, Worker heartbeat, activity audit,
  canonical interaction inspection, execution traces, and deployment history.
- Extend backup/restore to cover user-sensitive files.

## 2026-07-27

- Deploy reliability foundations covering durable jobs, model policy, bounded
  chat context, isolated worktrees, reproducible builds, and frontend toolchain.
- Establish full lifecycle P0 documentation and refocus the root README.

## 2026-07-26

- Add idempotent interview answers and durable chat turns.
- Add atomic Qdrant knowledge publication and rollback.
- Modularize FastAPI API composition and define persistence execution boundary.

## 2026-07-25

- Complete product experience P0–P2: profiles, today plan, rich sources,
  interview retries, learning, history, analytics, responsive accessibility,
  CI and release packaging.

Detailed evidence remains in `docs/exec-plans/completed/` and historical release
